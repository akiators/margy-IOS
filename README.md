# MargyT iOS Starter (не готовый мод TikTok)

Это стартовый SwiftUI-проект для планирования iOS-версии. Он **не содержит портированных функций MargyT и не модифицирует TikTok**. Переключатели в интерфейсе — только UI-заготовка, они пока ничего не меняют в TikTok.

## Что нужно для настоящего порта
Оригинальный MargyT — Android-патчер. Его обработка APK/DEX/Smali не работает с iOS-приложениями. Для каждой функции нужно отдельно исследовать реализацию и создать совместимый iOS-вариант. Некоторые функции могут быть невозможны или зависеть от серверов TikTok.

## Сборка
1. Загрузите эту папку в собственный GitHub-репозиторий.
2. Откройте проект на Mac с Xcode: `MargyT-iOS/MargyTiOS.xcodeproj`.
3. В Xcode выберите Target `MargyTiOS` → **Signing & Capabilities** → свою Team.
4. Для установки на свой iPhone подключите устройство и нажмите Run. Для распространения потребуется подходящая подпись.
5. Для IPA используйте **Product → Archive**, затем **Distribute App**. Для личной установки можно рассмотреть бесплатную подпись через Xcode, но она имеет ограничения и требует периодического переподписания.

## Можно ли без своего Mac?
Да, можно арендовать облачный Mac или использовать CI с macOS runner. Но для подписанного IPA всё равно понадобится настроить Apple signing credentials (сертификат и provisioning profile). Не загружайте секреты подписи в публичный репозиторий.
